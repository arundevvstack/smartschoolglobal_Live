# Customer Demo Checklist

**Pre-Flight Verification**
Before presenting the Smart School AI website to a Middle East school decision-maker, confirm the following:

- [ ] **Homepage loads correctly:** Hero, feature grid, and trust sections render without visual glitches.
- [ ] **Product is understandable in 10 seconds:** The hero clearly defines the product as an "Intelligent School Management Platform".
- [ ] **Product visuals are accurate:** All conceptual UIs are abstracted and contain no fabricated customer data.
- [ ] **No unsupported claims:** All metrics (94% fee collection, 68% admin reduction) match the Truth Check document.
- [ ] **Demo CTA works:** The primary "Book a Demo" buttons successfully route to `/book-demo`.
- [ ] **Demo form works:** The multi-step form functions and displays trust badges correctly.
- [ ] **Mobile works:** The site is fully responsive down to 320px with no horizontal overflow.
- [ ] **No console errors:** Client-side JavaScript executes cleanly.
- [ ] **SEO baseline works:** Canonical production URLs are driven by environment variables, not hardcoded development domains.
- [ ] **No fake logos:** Empty logo sections have been replaced by verified platform scale metrics.
- [ ] **No fake testimonials:** All trust elements rely on verified product capabilities and metrics.
- [ ] **Trust claims verified:** ISO 27001 and 99.9% Uptime claims are explicitly approved.
- [ ] **Contact information verified:** All routing and attribution logic in the Demo form is intact.
